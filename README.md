# Master Data Visualization: Companion Files

These are the companion files for the book *Master Data Visualization*. Each chapter has its own folder with:

- the data the chapter's examples use (`.csv` files),
- a notebook with every example from the chapter (`chapter-NN.ipynb`),
- the book's chart style (`book.mplstyle`).

## Download

1. Click the green **Code** button near the top of this page, then **Download ZIP**.
2. Find `master-data-visualization-main.zip` in your **Downloads** folder.
   - **Windows:** right-click it, choose **Extract All…**, click **Browse**, pick your **Documents** folder and click **Extract**.
   - **Mac:** double-click the ZIP file, then drag the new folder into **Documents**.

You now have a folder called `master-data-visualization-main` with `chapter-01`, `chapter-02` and so on inside.

## Charts in color

The `color-figures` folder has every chart in the book as a color picture, named by chapter (`ch09-...png` is from Chapter 9). Use it if you read the black-and-white paperback.

## Use

Section 1.1 of the book shows how to install Python, Jupyter and the chart libraries. Then start Jupyter, open a chapter folder and either open `chapter-NN.ipynb` or create your own notebook in the same folder, so it can find the data files by name.

The notebooks were tested with Python 3.14, pandas 3.0, matplotlib 3.11, seaborn 0.13 and plotly 7.1.

The interactive plotly charts in Chapters 16 to 18 appear when you run the cells in Jupyter. On this GitHub page they show as empty space.
